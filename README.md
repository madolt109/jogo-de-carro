# 🚗 Jogo de Carro

## 🚀 Sobre o Projeto
<p>
Este projeto é um jogo de carro desenvolvido utilizando 
<strong>HTML</strong>, <strong>CSS</strong> e <strong>JavaScript</strong>,
com foco em praticar lógica de programação e interatividade.
</p>

<p>
O jogo simula uma experiência simples de corrida, permitindo controlar
um carro e interagir com os elementos da tela em tempo real.
</p>

## 🎮 Funcionalidades
<ul>
  <li>Controle do carro pelo teclado</li>
  <li>Movimentação dinâmica</li>
  <li>Sistema de colisão</li>
  <li>Animações durante o jogo</li>
  <li>Atualização em tempo real</li>
</ul>

## 🧠 Tecnologias Utilizadas
<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>
